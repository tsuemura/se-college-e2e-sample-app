# 会議室予約システム 仕様書

バージョン: 2.0（1.0 からの変更点は [changes-v2.md](changes-v2.md) を参照）

## 1. 概要

社内の会議室を予約するための Web アプリケーションです。
ログインした利用者は、会議室の予約状況を確認し、新しい予約の登録や自分の予約のキャンセルができます。

- 対応ブラウザ: 最新の Chrome / Edge
- データはサーバーのメモリ上に保持され、サーバーを再起動すると初期状態に戻ります（演習用の仕様です）

## 4. 画面一覧

| 画面 | URL | ログイン |
| --- | --- | --- |
| ログイン画面 | `/login` | 不要 |
| 予約一覧画面 | `/` | 必要 |
| 新規予約画面 | `/reservations/new` | 必要 |

ログインが必要な画面に未ログインでアクセスすると、ログイン画面にリダイレクトされます。

すべての画面のヘッダーには「会議室予約システム」のタイトルが表示されます。ログイン中は、ヘッダーに次のものが表示されます。

- 「ログイン中: （氏名）」
- 「ログアウト」ボタン

## 5. 機能仕様

### 5.1 ログイン

- 入力項目: ユーザーID（必須）、パスワード（必須）
- 「ログイン」ボタンを押すと認証を行います
- 認証に成功すると予約一覧画面へ遷移します
- 認証に失敗すると、ログイン画面に「ユーザーIDまたはパスワードが正しくありません」と表示されます。入力したユーザーIDは保持され、パスワードは消去されます
- 画面下部にデモ用アカウントの一覧が表示されます

### 5.2 予約一覧

- すべての利用者の予約を、日付・開始時刻・会議室の順（昇順）に表示します
- 表示項目: 日付、時間（開始〜終了）、会議室、人数、目的、予約者、操作
- 自分の予約の行にのみ「キャンセル」ボタンが表示されます。他の利用者の予約には表示されません
- 予約が 1 件もない場合は「予約はありません」と表示します
- 「新規予約」ボタンを押すと新規予約画面へ遷移します（ヘッダーには新規予約へのリンクはありません）
- 予約登録・キャンセル・データ初期化の直後は、画面上部にメッセージを表示します
  - 予約登録後: 「予約を登録しました」
  - キャンセル後: 「予約をキャンセルしました」
  - 初期化後: 「データを初期化しました」

### 5.3 新規予約

入力項目は次のとおりです。

| 項目 | 形式 | 備考 |
| --- | --- | --- |
| 会議室 | 選択（A / B / C） | 「会議室A（定員6名）」のように定員つきで表示 |
| 日付 | 日付（YYYY-MM-DD） | |
| 開始時刻 | 選択 | 09:00 〜 17:30 の 30 分刻み |
| 終了時刻 | 選択 | 09:30 〜 18:00 の 30 分刻み |
| 参加人数 | 数値 | 初期値 1 |
| 目的 | テキスト（50文字まで） | |

「予約する」ボタンを押すと、次のルールで入力内容を検証します。

| # | ルール | エラーメッセージ |
| --- | --- | --- |
| R1 | 会議室が選択されていること | 会議室を選択してください |
| R2 | 日付が入力されていること | 日付を入力してください |
| R3 | 開始時刻・終了時刻が選択されていること | 開始時刻と終了時刻を選択してください |
| R4 | 終了時刻が開始時刻より後であること | 終了時刻は開始時刻より後にしてください |
| R5 | 目的が入力されていること | 目的を入力してください |
| R6 | 同じ会議室・同じ日付で、時間帯が重なる予約がないこと | 指定した時間帯はすでに予約されています |
| R7 | 参加人数が 1 以上の整数であること | 参加人数は1以上の整数で入力してください |
| R8 | 参加人数が会議室の定員以下であること | 参加人数が会議室の定員（6名）を超えています ※括弧内は会議室の定員 |

- R1〜R5、R7、R8 のエラーがある場合、R6 の重複チェックは行いません
- 参加人数が定員と同じ場合は予約できます（定員 6 名の会議室に 6 名は可、7 名は不可）
- 時間帯の重なりは「新しい予約の開始時刻 < 既存の予約の終了時刻」かつ「新しい予約の終了時刻 > 既存の予約の開始時刻」のときに発生します。たとえば 10:00〜11:00 の予約がある場合、11:00〜12:00 の予約は重複しません
- 別の会議室であれば、同じ日付・同じ時間帯でも予約できます
- エラーがある場合は新規予約画面に戻り、エラーメッセージを一覧表示します。入力内容は保持されます
- 検証に成功すると予約を登録し、予約一覧画面へ遷移して「予約を登録しました」と表示します。予約者にはログイン中の利用者が設定されます

### 5.4 予約のキャンセル

- 予約一覧画面で自分の予約の「キャンセル」ボタンを押すと、その予約を削除し、「予約をキャンセルしました」と表示します
- 確認ダイアログは表示しません
- 他の利用者の予約をキャンセルしようとした場合は「キャンセルできません」画面を表示します
- 存在しない予約をキャンセルしようとした場合は「予約が見つかりません」画面を表示します

### 5.5 ログアウト

- ヘッダーの「ログアウト」ボタンを押すとログアウトし、ログイン画面に「ログアウトしました」と表示します

### 5.6 データの初期化

- 画面下部の「データを初期化」ボタンを押すと、予約データを初期データ（6 章）に戻します
- ログイン状態は維持されます

## 7. 開発者・テスト用 API

画面を介さずに操作するための API です。認証は不要です。

| メソッド | URL | 説明 |
| --- | --- | --- |
| `POST` | `/api/reset` | 予約データを初期データに戻す。`{"ok":true}` を返す |
| `GET` | `/api/reservations` | 予約の一覧を JSON で返す |
